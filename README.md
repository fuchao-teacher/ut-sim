# 直探头课堂 UT 仿真 webapp

Vite + Three.js 超声检测（UT）直探头仿真培训系统。

## 技术栈

- Vite 8.x
- Three.js 0.186
- KaTeX (数学公式渲染)

## 快速开始

```bash
npm install
npm run dev
```

## 标签说明

`pre-upgrade` 标签标记 Phase A/B 布局升级前的基线版本。

## 媒体文件说明

大型教学视频 `angle-structure.mp4` (~32MB) 未包含在此仓库中。媒体文件存放于：

- `public/media/`
- `src/angle/assets/`

如需完整媒体资源，请在本地添加后使用。
